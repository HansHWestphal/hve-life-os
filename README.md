# HVE Life OS

Open application layer for the Human Value Exchange Five Wealth frame: Time, Physical, Mental, Social, and Financial.

This repository is the Life OS application. It is not the Hermes runtime and not the knowledge-and-operations control plane. Doctrine lives in [hve-knowledge-and-operations](https://github.com/HansHWestphal/hve-knowledge-and-operations). Entries do not.

## First module

`diary/` is the notebook container. It recreates the function of a magical diary — date, time, conditions, what happened, what is not concluded — without a ritual engine and without a recovered floppy.

Governing charter: `agent-communications/2026-10-03-hve-academia-esopeira-founding-charter-v1.1.md` in the knowledge repository.

The practitioner owns the notebook. Agents may prefill the clock and the sky. They do not close the entry.
